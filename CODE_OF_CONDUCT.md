# Code of Conduct

AlleleForge adopts the **[Contributor Covenant, version 2.1][covenant]** as its code of
conduct. The full text is maintained by the Contributor Covenant project and is
authoritative there; this file records the adoption, the scope, and how to report.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

It applies in every project space — the repository, issues, pull requests, discussions,
and releases — and whenever someone is representing the project in a public space.

## In short

Be decent to people. Assume good faith, disagree about the work rather than the person,
and accept that a technical position can be wrong without its author being a fool. This
is a scientific tool: correcting an error is a contribution, and receiving a correction
is ordinary. Harassment, personal attacks, and demeaning or exclusionary conduct are not
welcome here.

## Reporting

Report a concern to the project maintainers through GitHub:

- **Sensitive or personal reports:** open a [private security advisory][advisory], which
  is visible only to the maintainers. It is the report channel that exists today for
  anything you do not want in public.
- **Anything else:** open an [issue][issues].

Reports are handled by the maintainers, who will keep the reporter's identity
confidential. Maintainers who are the subject of a report recuse themselves from
handling it.

[advisory]: https://github.com/clay-good/alleleforge/security/advisories/new
[issues]: https://github.com/clay-good/alleleforge/issues

## Enforcement

The Contributor Covenant's enforcement guidelines — correction, warning, temporary ban,
permanent ban — apply as written at the link above.
