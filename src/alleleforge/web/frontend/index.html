AlleleForge

Variant in, corrective edit out.

Research use only. AlleleForge is not a medical device and does not provide medical advice. Off-target nominations are computational and must be experimentally validated. All compute is local — no sequence data is transmitted off this deployment.
This deployment requires an API token. Every request except the health check is refused without it. Paste the token the operator set as ALLELEFORGE_API_TOKEN; it is held for this browser tab only and sent to this deployment as an X-API-Token header.
Coordinates (chrom:pos:ref>alt, 1-based as in a VCF), a VCF record, or a genomic HGVS expression (chr1:g.500T>C). A ClinVar accession, a dbSNP rsID or a coding/protein HGVS string (c./p.) needs a lookup this deployment has no way to supply, so those are refused with a message naming the coordinate form.
